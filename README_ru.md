## Что делает макрос

Макрос читает цветную сетку прямо с экрана, группирует клетки по цветовым регионам и решает головоломку перебором с возвратом по правилам игры: одна кошка в строке, одна в столбце, одна на цветовой регион, кошки не касаются друг друга даже по диагонали. Найденное решение отыгрывается по клеткам игровым циклом из двух тапов, сначала крестик, затем кошка. После последней кошки макрос дожидается таблицу лидеров, закрывает ее и запускает следующий уровень. Цикл бесконечный, поэтому макрос может фармить уровни без присмотра.

## Требования

Макрос работает на любом Android устройстве или эмуляторе, где запускается Macrorify. Перед первым стартом убедитесь, что:

- Macrorify установлен и настроен метод касаний (Accessibility Service либо Native Service на эмуляторах и Android 7).
- Macrorify выдано разрешение на захват экрана.
- MeowDoku установлена и выполнен вход, с главного меню доступен уровень.

## Установка

1. Скачайте последний файл `.mrscript` со страницы [Releases](../../releases).
2. В Macrorify импортируйте файл через меню импорта макросов.
3. Откройте MeowDoku и останьтесь на главном меню либо внутри уровня со свежим полем.
4. Запустите макрос из оверлея Macrorify.

Макрос сам определяет, запущен он из главного меню или из уровня, и ведет себя соответственно.

## Как это работает

Каждая итерация основного цикла проходит одни и те же этапы:

1. Определение старта. Экран проверяется на наличие цветной сетки. Если сетки нет, макрос ищет оранжевую кнопку уровня в главном меню и нажимает ее.
2. Чтение поля. Горизонтальные и вертикальные линии сканирования находят строки и столбцы по насыщенности цвета, поэтому макрос не зависит от размера поля (от 4x4 до 12x12) и от разрешения устройства.
3. Группировка регионов. Цвета всех клеток считываются одним снимком и кластеризуются в цветовые регионы сравнением CIE76 delta E.
4. Решение. Перебор с возвратом расставляет по одной кошке в строку с ограничениями на столбец, регион и соседство.
5. Расстановка. Каждая целевая клетка получает два тапа: первый ставит крестик, второй превращает его в кошку.
6. Конец уровня. При поражении нажимается кнопка повтора и уровень решается заново. При победе макрос ждет восемь секунд после последней кошки, закрывает таблицу лидеров и нажимает кнопку следующего уровня.

## Конфигурация

Настраиваемые константы находятся в начале файла макроса:

| Константа | По умолчанию | Значение |
| --- | --- | --- |
| `PLACE_TAPS` | `2` | Тапов на клетку, цикл крестик затем кошка |
| `TAP_HOLD` | `50` | Время удержания одного тапа, мс |
| `TAP_GAP_INNER` | `150` | Пауза между двумя тапами по одной клетке, мс |
| `TAP_GAP` | `300` | Пауза между разными клетками, мс |
| `CLOSE_DELAY` | `8000` | Пауза после последней кошки перед закрытием таблицы лидеров, мс |
| `DEBUG` | `true` | Отладочные тосты с размером найденного поля |

## Совместимость с устройствами

Координаты хранятся относительно опорного экрана 1080x2340 и пересчитываются в рантайме через `Env.deviceW()` и `Env.deviceH()`, поэтому ручная подгонка на других разрешениях не нужна. Поле ищется сканированием, а не по фиксированным координатам, что сохраняет работоспособность при разных размерах сетки и смещениях разметки.

## Устранение неполадок

**Макрос ничего не делает на старте.** Он ожидает либо главное меню с оранжевой кнопкой уровня, либо полностью отрисованное поле. Закройте диалоги и заставки перед запуском.

**Появляется тост "Regions X of Y".** Кластеризация цветов увидела лишние регионы, обычно потому что поле еще анимируется. Макрос повторяет попытку сам; если это повторяется, немного увеличьте `COLOR_DE`.

**Таблица лидеров не закрывается.** Увеличьте `CLOSE_DELAY` на одну или две секунды.

**Кошки не ставятся.** Проверьте метод касаний в Macrorify; эмуляторам и устройствам на Android 7 нужен Native Service.
